# Project documentation

## Files

- `v3_beginner_notes.docx`: six-page beginner-friendly V3 guide with a function
  flow diagram, inputs/returns, charging helpers, matching, and worked examples.
- `legacy_readme.md`: the previous root README, preserved for context about
  earlier simulator versions, controls, algorithms, and measurements.
- `changes.md`: development notes describing the progression from baseline
  scoring through weighted/global scheduling, charging preparation, planning,
  and the historical rule-based assignment FSM.

The Markdown history files are historical references, not authoritative instructions for the
current code. Some described APIs, algorithms, commands, and features no longer
exist in the same form. Do not assume an old measured result describes the
current workload or implementation.

For the current layout and installation, start with [the root README](../README.md).
For current scheduling behavior, read [assignment algorithms](../swarm_drone/assignment_algorithms/README.md).
For saved V3 measurements, see [results](../results/README.md).
